# Licence texts

The full texts of the licences named in this repository, one file per SPDX
identifier, following the [REUSE](https://reuse.software) convention.

They were taken from the SPDX License List as published in the npm package
`spdx-license-list` 6.12.0 (`spdx-full.json`), which reproduces the texts
maintained by the SPDX project. `tools/generate_notice.py` reads them from
here, so the NOTICE shipped in the APK carries the same texts wherever it is
generated.

| File | Used for |
|---|---|
| `CC-BY-SA-4.0.txt` | This project's documentation (see `LICENSING.md`) |
| `Apache-2.0.txt`, `MIT.txt`, `BSD-2-Clause.txt`, `BSD-3-Clause.txt`, `PSF-2.0.txt`, `Unicode-3.0.txt` | Third-party components, as recorded in `NOTICE` and `LICENSING_AUDIT.md` |

The software licence texts are at the repository root: `LICENSE`
(AGPL-3.0-only) and `LICENSE-COMMERCIAL.md`.
